# Один репозиторий с раздельными backend/ и frontend/

Лекция «Инженерный старт проекта» требует держать API и клиент раздельно. Лаба 1 требует отдельные README для фронтенда и бэкенда. Но `docker-compose` для локального запуска (лабы 1–2) и pre-commit (лаба 1) относятся к проекту целиком. Поэтому проект — один git-репозиторий: `backend/` и `frontend/` в нём самостоятельны (у каждой части свои README, `.gitignore`, `Dockerfile`, линтер, форматтер, переменные окружения, и части не импортируют код друг друга), а в корне лежат только общие `docker-compose.yml`, `.pre-commit-config.yaml`, мониторинг и документация.

## Considered Options

- Два репозитория, как в прошлом курсе: разделение строже, но `docker-compose` пришлось бы класть в один из них со ссылкой на соседнюю папку `../frontend`, а pre-commit настраивать дважды. Ветки лабораторных пришлось бы синхронизировать в двух местах.
